Matrix AI is an Android app with a sleek Matrix-inspired interface (green digital rain on black) that lets you download and run AI language models locally on your device. Powered by llama.cpp, it supports any GGUF-format model for private, on-device inference.

Key Features:
- Matrix-style UI with falling green code rain animation
- On-device AI inference - your data stays private
- Cloud AI agent integration (OpenAI, Grok, Claude, DeepSeek, Gemini)
- Download models directly from HuggingFace
- Customizable inference parameters (temperature, min-p, context size)
- Task templates for quick AI actions (summarize, rewrite, etc.)
- Chat management with folders
- Beautiful Matrix-themed animations for all states

Matrix AI also supports cloud AI agents. Configure API keys for OpenAI GPT, xAI Grok, Anthropic Claude, DeepSeek, and Google Gemini to access cloud-based AI models alongside local inference.
